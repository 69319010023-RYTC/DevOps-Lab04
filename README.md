# DevOps-Lab04 — FixFlow

FixFlow เป็นหน้าเว็บไซต์ตัวอย่างสำหรับบริการ IT Support ภายในองค์กร ออกแบบมาเพื่อแนะนำบริการและอธิบายขั้นตอนการแจ้งปัญหา โดยเน้นการนำเสนอที่อ่านง่ายและรองรับการใช้งานทั้งบนคอมพิวเตอร์และโทรศัพท์มือถือ

## เนื้อหาบนเว็บไซต์

- **ส่วนแนะนำบริการ:** อธิบายแนวคิดของ FixFlow พร้อมปุ่มเชื่อมโยงไปยังบริการและช่องทางติดต่อ
- **ตัวอย่างสถานะการแจ้งซ่อม:** แสดงการ์ดตัวอย่างรายการปัญหาและความคืบหน้า เพื่อสื่อให้เห็นภาพการติดตามงาน
- **รายการบริการ:** ครอบคลุมปัญหาคอมพิวเตอร์และอุปกรณ์ เครือข่ายและอินเทอร์เน็ต รวมถึงโปรแกรมและบัญชีผู้ใช้
- **ขั้นตอนการรับบริการ:** เริ่มจากแจ้งอาการ ทีมงานรับเรื่อง และติดตามจนแก้ไขเรียบร้อย
- **ส่วนติดต่อ:** แนะนำให้ติดต่อทีม IT Support ผ่านช่องทางภายในองค์กร

## เทคโนโลยี

- HTML5 สำหรับโครงสร้างและเนื้อหาของหน้าเว็บ
- CSS3 ที่เขียนรวมอยู่ในไฟล์ HTML สำหรับการออกแบบ การจัดวาง และการรองรับหน้าจอขนาดต่าง ๆ
- ไม่มีไลบรารีหรือแพ็กเกจภายนอกที่ต้องติดตั้ง

## วิธีเปิดใช้งาน

เปิดไฟล์ `idex.html` ด้วยเว็บเบราว์เซอร์ได้โดยตรง หรือใช้ส่วนขยายสำหรับเปิดไฟล์ HTML ในเครื่องมือพัฒนาเว็บ

## ข้อจำกัดของตัวอย่าง

โปรเจกต์นี้เป็นหน้าเว็บไซต์ส่วนหน้าแบบคงที่ (static frontend) ปุ่มและเมนูใช้เลื่อนไปยังส่วนต่าง ๆ ภายในหน้า ไม่มีระบบส่งคำขอแจ้งซ่อมจริง ไม่มีการบันทึกข้อมูล และการ์ดสถานะเป็นข้อมูลตัวอย่างเท่านั้น
